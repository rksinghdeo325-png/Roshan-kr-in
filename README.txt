RAREISM Inventory Android App v2.1

Features:
- Search Style / Barcode / Product / Colour / Size
- Shows Size and CLOSING/SOH
- UPDATE SHEET: select the latest XLS/XLSX and replace the local inventory
- SOLD: search one exact matching item, enter quantity, tap SOLD
- SOLD immediately reduces the local SOH on the phone and saves it
- No Android Studio is needed for daily use after the APK is installed

Daily:
1. Search the exact style/barcode.
2. Enter sold quantity.
3. Tap SOLD.
4. SOH changes immediately.
5. Import the latest master Excel with UPDATE SHEET when required.

Important:
SOLD changes the phone's local inventory only. UPDATE SHEET replaces the local inventory with the selected Excel file.
